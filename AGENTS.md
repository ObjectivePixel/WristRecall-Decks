# WristRecall deck rules

When creating or revising a WristRecall deck:

- Treat `WRISTRECALL_COVER_STYLE.md` as the authoritative specification for the cover image, cover concept-selection workflow, final cover export, and companion theme gradient.
- Read that file before proposing, generating, revising, evaluating, or delivering a cover or choosing `gradientColors`.
- Its rules override any earlier or generic guidance about cover composition, rendering style, branding, colours, gradients, or cover-delivery workflow.
- Store the approved two-colour gradient in `deck.json` as `#RRGGBBAA`, normally by appending `FF` to each opaque `#RRGGBB` value supplied with the final cover.
- Do not alter unrelated deck-authoring requirements in `AUTHORING.md`.
